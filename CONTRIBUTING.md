# Contributing to MoonOrbit

Thank you for your interest in contributing to MoonOrbit! We welcome all contributions, including bug reports, feature requests, documentation improvements, and code submissions.

## How to Contribute

1. **Fork the Repository**: Create a fork of the repository on GitHub or GitLink.
2. **Clone the Fork**: Clone the fork to your local machine:
   ```bash
   git clone https://github.com/your-username/moonorbit.git
   cd moonorbit
   ```
3. **Set Up the Toolchain**: Make sure you have the latest MoonBit toolchain installed (0.10.3 or newer stable version).
4. **Create a Branch**: Create a descriptive feature branch:
   ```bash
   git checkout -b feat/your-feature-name
   ```
5. **Implement and Test**: Write clean MoonBit code, format it, and add tests for any new functionality:
   ```bash
   moon fmt
   moon check
   moon test --target native
   ```
6. **Submit a Pull Request**: Push your branch to your fork and submit a PR to the `main` branch.

## Code of Conduct

- Be respectful, helpful, and welcoming to all contributors.
- Keep discussions professional and focused on project improvement.
